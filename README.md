# Customer Churn Analysis (Python + SQL)

# Project Goal

The goal of this project is to analyze customer churn behavior and identify key factors that influence whether a customer leaves or stays.

## Dataset

The dataset contains customer information including:

- Customer tenure
- Contract type
- Monthly charges
- Total charges
- Churn status (Yes/No)

## Approach

1. Loaded and explored the dataset
2. Checked for missing values and cleaned data
3. Performed exploratory data analysis (EDA)
4. Analyzed churn patterns across different customer segments
5. Visualized key insights using Python
6. Used SQL-style thinking for aggregations and segmentation

## Key Insights

- Customers with month-to-month contracts are more likely to churn
- Short-tenure customers have the highest churn rate
- Higher monthly charges are associated with higher churn probability
- Longer contracts improve customer retention

  ## Visualizations

- Churn rate by contract type
- Customer tenure distribution
- Monthly charges vs churn
